## 功能

- 在「发现」页流式浏览：滑动 → 点开当前屏幕的一篇 → 看完返回 → 继续滑
- 按概率给笔记点赞、收藏
- 按概率触发评论，评论内容从你设置的评论池里随机挑选（不会重复）
- 按随机数量给评论点赞
- 随机停留、随机间隔、随机动作组合，并带每日/单次上限
- 所有数据（今日计数、浏览记录、评论池）只存在你本地浏览器里

## 安装

1. 在 Edge / Chrome 安装 [篡改猴（Tampermonkey）](https://www.tampermonkey.net/)
2. 打开篡改猴管理面板，点左上角 `+` 新建脚本
3. 把 [`xhs-bot.user.js`](xhs-bot.user.js) 的全部内容粘贴进去
4. `Ctrl + S` 保存，确认脚本开关是启用状态
5. 打开 `https://www.xiaohongshu.com/explore`，右下角会出现控制面板

## 使用

1. 登录小红书网页版
2. 面板里设置好参数，**第一次先勾选「试运行」**，点「开始」
3. 观察右下角日志，确认能正常打开笔记、识别按钮
4. 试运行正常后，取消勾选，正式运行

运行过程中页面会整页刷新，这是正常现象；想停止就点面板上的「停止」。

## 参数

| 项 | 默认 | 说明 |
|---|---|---|
| 浏览篇数 | 10 | 一轮看几篇 |
| 评论点赞/篇 | 3 | 每篇随机点 0~N 条评论赞 |
| 每日点赞上限 | 100 | 笔记赞 + 评论赞合计 |
| 点赞概率 % | 65 | 每篇给笔记点赞的概率 |
| 收藏概率 % | 22 | 每篇收藏的概率 |
| 评论概率 % | 30 | 每篇触发评论的概率 |
| 每篇评论 0~N | 5 | 触发后随机发 1~N 条 |
| 每日评论上限 | 15 | 当天累计 |
| 单次评论上限 | 5 | 单次运行累计 |
| 点赞 / 收藏 / 评论 | 开 | 总开关 |
| 评论池 | 空 | 每行一条，留空则不发评论 |
| 试运行 | 勾选 | 只识别、不操作 |

修改后自动保存在浏览器 `localStorage`，刷新不丢。

## 工作原理

脚本通过 `document.querySelectorAll` 读取页面已经渲染出来的 DOM：

- 笔记链接来自信息流卡片上的 `<a href="...?xsec_token=...">`，脚本只是复用，不生成、不破解 token
- 点击卡片使用 `element.click()`，由页面自己的事件处理逻辑打开笔记
- 是否已点赞通过图标引用判断：`#like_b` 未赞，`#liked` 已赞
- 每次操作后都会重新读取状态，失败则跳过，不重试

脚本不调用接口、不伪造请求、不修改签名。

## 已知限制

- 小红书改版后选择器可能失效，需要更新代码
- 如果页面开始检查 `event.isTrusted`，脚本的点击会失效
- 自动化行为可能触发平台风控，无法保证账号安全
- 只在网页版可用，与 App 无关
